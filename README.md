# NEXUS BI — Autonomous AI Business Intelligence Analyst

> **"Dashboards show you what happened. NEXUS finds out why."**

NEXUS BI is an autonomous, agentic business intelligence platform engineered to turn raw tabular business records into evidence-backed decisions. Unlike traditional BI tools or simple Text-to-SQL dashboards, NEXUS BI executes a multi-step recursive investigation loop using deterministic calculation tools to uncover root causes behind financial distress, margin degradation, and business anomalies.

---

## 1. Problem Statement & Solution

### The Problem
* **Static Dashboards:** Require manual metric slicing, pivot tables, and human intuition to diagnose performance drops.
* **Naive LLM Text-to-SQL:** Prone to hallucinations, SQL syntax errors, and isolated single-pass answers that lack business context or validation.
* **Code Execution Risks:** Passing raw database credentials or executing arbitrary Python code generated by LLMs poses substantial security vulnerabilities.

### The NEXUS BI Solution
* **Autonomous Recursive Investigation:** When an anomaly is detected (e.g., negative profit in Q2), the agentic supervisor autonomously formulates sub-hypotheses and selects tools to drill down into categories, products, and discount tiers.
* **100% Deterministic Calculations:** Numerical truth is computed strictly through DuckDB and Python analytical tools—the LLM is restricted to semantic reasoning, planning, and executive synthesis.
* **Evidence-Grounded Recommendations:** Every finding is linked to verifiable calculations, complete with an execution trace and prioritized business actions.
* **One-Click C-Suite Briefs:** Automated PDF generation producing executive-ready briefings formatted for board and management reviews.

## 4. Key Features

###  Ingestion & Data Hygiene Auditing
* Drag-and-drop ingestion for `.csv` and `.xlsx` files up to 50 MB[cite: 1].
* Automated conversion to compressed Apache Parquet for high-speed DuckDB querying[cite: 1].
* Deterministic Data Quality Score (0–100) evaluating null rates, schema consistency, duplicates, and column cardinality[cite: 1].

###  Multi-Step Autonomous Investigation Loop
* Employs an agentic ReAct loop that executes sequential tools based on analytical findings[cite: 1].
* Recursively investigates contributing factors when negative profit or significant variance is detected[cite: 1].
* Exposes a live **Agent Investigation Trace** in the UI to display operational steps without revealing private reasoning[cite: 1].

###  Dynamic Visualization Layer
* Automatically determines and renders appropriate visual representations:
  * Categorical and entity rankings $\rightarrow$ **Bar Charts**[cite: 1]
  * Period-over-period and margin changes $\rightarrow$ **Line Trends**[cite: 1]
  * Distribution and contribution brackets $\rightarrow$ **Pie & Tier Graphs**[cite: 1]

###  One-Click C-Suite PDF Reports
* Generates a formal executive PDF brief directly from active findings[cite: 1].
* Includes cover metadata, executive summary, KPI baseline tables, root-cause findings, and prioritized strategic actions[cite: 1].
